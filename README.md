# Student Attendance System (C)

This is a C-based Student Attendance System with features:

## Features
- Login system (Admin)
- Add student
- Mark attendance (date-wise)
- Search student
- Delete student
- Attendance percentage
- File storage (binary file)

## Default Login
Username: admin  
Password: 1234

## How to Run
1. Compile:
   gcc main.c -o attendance
2. Run:
   ./attendance
